# Призупинення розробки і GitHub Actions — 11.10.2026

Наказ власника: активна тільки розробка канонічного SENS Core у `juv4uk/sens`.
Цей репозиторій **заморожено**: не запускати його CI, інші тести, компіляцію,
GPU/FPGA/native jobs, випуски або автоматичні синхронізації; не створювати
нові гілки чи дослідні ланки. Всі попередні workflows перенесено побайтно
з `.github/workflows/` до цієї директорії (GitHub Actions їх не сканує).
Збережено тільки `.github/workflows/forbid-new-branches.yml` для контролю
незмінної політики гілок; це не продовження розробки ядра.

Жоден старий workflow не є доказом нового green CI. Нові дії з розробки,
перевірок або відновлення workflows потребують явної нової вказівки власника.
Архівна дата: 2026-10-11. Репозиторій: juv4uk/sens-futhark.
